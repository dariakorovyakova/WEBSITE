# DROP LAB — интернет-магазин (фронтенд)

Учебный итоговый проект: полностью рабочий фронтенд интернет-магазина уличной одежды и
кастомного мерча **DROP LAB**. Без бэкенда и базы данных — всё работает в браузере
(данные корзины хранятся в `localStorage`). Сайт адаптивный: корректно отображается
на ПК, планшете и телефоне.

## Страницы

| Файл | Раздел | Что внутри |
|------|--------|------------|
| `index.html` | Главная | Hero, блок «О бренде», преимущества, фирменный знак, популярные товары |
| `catalog.html` | Продукты | Каталог с фильтрами (теги, цвет, размер, цена) и поиском |
| `new.html` | Новинки | Товары с пометкой «Новинка» |
| `constructor.html` | Свой дизайн | Конструктор кастомной вещи с живым превью (макеты футболки, худи, сумки) |
| `cart.html` | Корзина | Список товаров, количество, итог, оформление заказа |
| `contacts.html` | Контакты | Адрес, телефон, соцсети и форма обратной связи |
| `delivery.html` | Доставка и оплата | Способы доставки и оплаты заказа |
| `returns.html` | Возврат | Условия и порядок возврата и обмена |
| `retailers.html` | Официальные ритейлеры | Wildberries, OZON и Lamoda |

## Реализованные механики

- **Корзина** — кнопка «В корзину», счётчик в шапке, страница корзины с изменением
  количества, удалением и подсчётом суммы (товары + доставка). Сохраняется между
  посещениями через `localStorage`.
- **Фильтры и поиск** в каталоге — по тегам, флагам (новинки/распродажа/коллаборации),
  цвету, размеру и цене (ползунок). Реально фильтруют витрину.
- **Конструктор «Свой дизайн»** — выбор модели (макет футболки, худи или сумки меняется
  на превью), цвета вещи, цвета надписи и текста с обновлением превью в реальном времени;
  результат добавляется в корзину.
- **Формы** (заявка, обратная связь, оформление, вход) — с валидацией (в т.ч. телефон:
  начинается с +7, 7 или 8 и ровно 11 цифр), имитацией отправки и экраном успеха.
- **Адаптивность** — мобильное меню-«бургер», выезжающая панель фильтров на телефоне,
  перестроение сеток.

## Технологии

Чистый HTML + CSS + JavaScript, без сборщиков и зависимостей. Шрифт Inter
подключается с Google Fonts. Использованы `flex`, `grid` и `position` для вёрстки.

```
css/styles.css      — все стили и адаптив
js/products.js      — данные товаров
js/main.js          — корзина, шапка, модалки, тосты, валидация форм
js/catalog.js       — фильтры каталога
js/cart.js          — страница корзины
js/constructor.js   — конструктор «Свой дизайн»
```

## Запуск локально

Просто откройте `index.html` в браузере. Либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта (вместе с папками
   `css`, `js`). Файл `index.html` должен лежать в корне репозитория.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник **Deploy from a branch**,
   ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Все ссылки внутри сайта относительные, поэтому он работает на GitHub Pages без
дополнительной настройки.
